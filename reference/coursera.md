# Coursera picks

You have free Coursera access, so cost is not the filter. **Quality and fit** are. Every Coursera course that appears in this roadmap is judged here. Ratings and like-rates come from the Coursera listing pages as searched in November 2026.

## Verdicts

| Verdict | Course | Where | Why |
|---|---|---|---|
| Take | [Reinforcement Learning Specialization (U Alberta)](https://www.coursera.org/specializations/reinforcement-learning) | [L6A](levels/L6-frontier-core.md) | Rigorous, built on Sutton and Barto, real coding. Best of the set. |
| Take | [Princeton Algorithms, Part I](https://www.coursera.org/learn/algorithms-part1) | [L1](levels/L1-cs-core.md) | The algs4 lectures with graded assignments. 97% liked. |
| Take | [Stanford Algorithms Specialization](https://www.coursera.org/specializations/algorithms) | [L1](levels/L1-cs-core.md) | Best proofs-and-intuition treatment of divide and conquer, graphs, DP. Overlaps Princeton, so pick one as the main. |
| Take | [Nand to Tetris, Parts I and II](https://www.coursera.org/learn/nand2tetris2) | [L1](levels/L1-cs-core.md) | About 95% five-star. Hard and worth the time. |
| Take | [Cryptography I (Boneh)](https://www.coursera.org/learn/crypto) | [L1](levels/L1-cs-core.md) | 96% liked; the standard first crypto course. |
| Take | [Programming Languages, Part A (Grossman)](https://www.coursera.org/learn/programming-languages) | [L1](levels/L1-cs-core.md) | 4.9 rating; teaches you to think in types and semantics. |
| Take | [Machine Learning Specialization (Ng)](https://www.coursera.org/specializations/machine-learning-introduction) | [L3](levels/L3-classical-ml.md) | Best gentle on-ramp before CS229. Updated September 2026. |
| Maybe | [Imperial: Mathematics for ML](https://www.coursera.org/specializations/mathematics-machine-learning) | [L2](levels/L2-math.md) | Good for rebuilding intuition; light on proofs. Skip if 18.06 feels fine. |
| Maybe | [Deep Learning Specialization (Ng)](https://www.coursera.org/specializations/deep-learning) | [L4](levels/L4-deep-learning.md) | Clear lectures, but Karpathy and UDL are better primary sources. Updated September 2026; check whether the assignments are still TensorFlow-based. |
| Maybe | [DeepLearning.AI: Math for ML and DS](https://www.coursera.org/specializations/mathematics-for-machine-learning-and-data-science) | [L2](levels/L2-math.md) | Friendly and visual, but shallow. A warm-up, not the spine. |
| Maybe | [Generative AI with LLMs](https://www.coursera.org/learn/generative-ai-with-llms) | [L5](levels/L5-transformers-llms.md) | Good short overview; labs are thin and AWS labs can cost money. |
| Skip | [IBM Data Science Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-science) | [Track H](tracks/H-data-science.md) | Shallow and weak as a signal. Only if you want a structured pandas/SQL start. |
| Skip | [Intro to Multimodal AI with Hugging Face](https://www.coursera.org/learn/introduction-to-multimodal-ai-with-hugging-face) | [Track C](tracks/C-vlm-multimodal.md) | New (June 2026) and unvetted. The free HF courses and 6.S184 cover the ground. |
| Skip | DeepLearning.AI NLP Specialization | [Audit](levels/AUDIT-OLD-ROADMAP.md) | Pre-LLM content. CS224N and CS336 replace it. |

## What was not checked

The workspace this was built in could not open course sites directly, so the checks are from web search results, not from loading each page. The GitHub Action in this repo runs the link checker weekly from GitHub's network, which will catch dead links.
